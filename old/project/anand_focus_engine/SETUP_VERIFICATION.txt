## ⚙️ CONFIGURATION GUIDE

### Change Default Password
1. Open `config.json`
2. Find: `"emergency_override_password": "focus2026"`
3. Change to your password: `"emergency_override_password": "your_password"`
4. Save file

### Add Blocked Sites
1. Open `config.json`
2. Find: `"blocked_sites": [...]`
3. Add to array: `"yoursite.com"`
4. Also add window title in: `"blocked_window_titles": [..."`
5. Save file

### Adjust Focus Durations
1. Open `config.json`
2. Find: `"focus_session_durations": [25, 45, 60]`
3. Change to desired minutes: `[30, 50, 90]`
4. Save file

### UI Customization
1. Open `config.json`
2. Section: `"ui_overlay": {...}`
   - `opacity`: 0.0 (transparent) to 1.0 (opaque)
   - `top_bar_height`: Pixels (60 default)
   - `update_interval`: Milliseconds (1000 = 1 sec)
